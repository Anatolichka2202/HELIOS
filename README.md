# HELIOS

A Solar System-scale civilization strategy game.

## Products
- `pc/` — Unreal Engine 5 / C++ flagship (planned)
- `mobile/` — Unity / C# mobile client (planned)
- `lite/` — browser prototype (planned)
- `core/` — C++ simulation core (planned)
- `design/` — game design, roadmap and architecture (planned)

This repository is in early prototyping. The game is not production-ready.
