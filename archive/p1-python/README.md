# HELIOS — headless prototype 0.1 (P1)

Preserved historical experiment from `HELIOS_headless_P1.zip`, not the production simulation. Python 3.10+, no external dependencies.

```bash
cd archive/p1-python
python demo.py
python -m unittest discover -s tests -v
```

Includes deterministic ticks, energy allocation, research, construction, atmospheric compressor crisis, two decision branches, JSON saving and five tests.

Game economics are placeholders and this module is **not** used by current Lite, PC or Mobile clients. The source is retained to preserve research history and tests.
