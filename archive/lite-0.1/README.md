# HELIOS Lite — interactive prototype 0.1

Open `index.html` in any modern browser. No server or dependencies needed.

## Implemented
- Interactive map of eight planets in the Solar System (schematic orbits)
- Campaign and sandbox session modes
- Projects, annual resource income, research points and event log
- Local save/load using browser localStorage
- Responsive mobile layout

## Not implemented
- Real orbital physics, accurate resource economics, actual campaign branching, multiplayer, video, music, real-time rendering, payment systems
- iOS/Android native builds and Unreal Engine client

This is a gameplay/UI demonstrator, not a complete game. Orbital radii and positions are deliberately not to scale.
