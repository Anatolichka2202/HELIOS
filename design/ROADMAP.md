# HELIOS roadmap

## Product tracks
- PC: Unreal Engine 5/C++ — premium Solar System-scale strategy, campaign and sessions.
- Mobile: Unity/C# — independent touch-first Android/iOS strategy.
- Lite: static browser client — rapid validation and first public playtests.
- Core: C++ simulation and shared data contracts.

## Milestones
1. Publish Lite over HTTPS, validate on iPhone and Android; stabilize economic loop.
2. Expand celestial catalog to moons, belts, stations; implement routes and travel-time constraints.
3. Integrate data schema across all clients; build and test Unity/UE projects.
4. Add campaign decisions, crises, faction interactions and session objectives.
5. Recruit first playtesters; measure retention and willingness to pay before choosing monetization.

## Definition of done
No task is complete without source committed, a repeatable test or manual test checklist, and an honest build status.
