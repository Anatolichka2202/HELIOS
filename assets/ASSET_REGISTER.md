# HELIOS — Реестр визуальных материалов

| Ресурс | Где хранится | Происхождение | Назначение | GitHub |
|---|---|---|---|---|
| `lite/assets/venus-clouds.svg` | Lite runtime | Авторский векторный SVG, написан для проекта | Венерианская атмосфера и аэростат в шапке веб-игры | **В репозитории** |
| `a_wide_cinematic_sci_fi_scene_of_a_venus_like_atmo.png` | Исходный сгенерированный файл в переписке ChatGPT | ImageGen, концепт Венеры с аэростатом | Арт-референс | **Пока не перенесён:** бинарный PNG ~1,97 МБ |
| Изображения в ответах через `AsyncImage` | Динамические внешние поисковые иллюстрации | Третьи стороны, без подтверждённых прав | Только визуальные референсы в беседе | **Не переносить без лицензии** |
| Скриншоты интерфейса | Нет подтверждённых файлов | Предстоит снять после запуска сайта/Unity/Unreal | Проверка UI | Не созданы |

Нельзя объявлять внешние изображения собственностью HELIOS. Экспортные PNG, исходники и версии лицензий следует хранить с однозначными именами и атрибуцией в `assets/concept-art/` и `assets/licenses/`, когда соответствующие файлы доступны.

## Политика

1. Любой ассет, используемый игрой, должен иметь файл в Git и запись в этом реестре.
2. Большие бинарники при росте проекта переводим в Git LFS; **сейчас Git LFS не настроен**.
3. Исключить внешние изображения без лицензии и неопределённый юридический статус.
4. Концепты и runtime assets разделены: наличие красивого арта **не** означает, что он уже встроен в игру.
