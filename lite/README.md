# HELIOS Lite — Venus Initiative (0.3)

The first playable vertical slice focuses on **Venus**. The full HELIOS franchise remains Solar System-wide.

## Prototype features
- Venus Campaign and Venus Session modes.
- Fictional Soviet classified-archive hook, Russian initiative and international cooperation.
- Four operational zones: orbit, cloud deck, lower atmosphere, surface.
- Eight engineering projects with prerequisites, credits, science, energy and supplies.
- Yearly turns, atmospheric hazard events and browser-local saves.
- Responsive layout aimed at touch devices.

## Run
Serve the `lite/` directory via `python3 -m http.server 8080`, then open http://localhost:8080.

GitHub repository code is **not** a public playable website. Deploy the directory to static HTTPS hosting and test on a real iPhone.

## Status
Early gameplay sketch. Economics and atmospheric risk are illustrative, not scientifically calibrated. Device tests and public deployment are not yet confirmed.

See `design/VENUS_CAMPAIGN.md` and `design/VENUS_VERTICAL_SLICE.md`.
