# HELIOS Lite

Mobile-friendly browser prototype with eight selectable planets, construction, Earth-linked export logistics, yearly production, campaign/session starting modes, and local saves.

Run: `python3 -m http.server 8080` from this folder; open http://localhost:8080.

No build dependencies. Intended for static HTTPS hosting (e.g. GitHub Pages). Simulation values are placeholders, not a final economic balance or physical model.
